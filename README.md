
# MSS 2026–2035 Strategic Intelligence Portal

## What this ZIP contains
- `app.py` — Premium Streamlit app with no sidebar.
- `mss_master_database.json` — Full 36-cell strategy database.
- `requirements.txt` — Streamlit dependency.

## How to run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Main features
- Premium 6×6 MSS framework matrix.
- Click any P1D1–P6D6 cell.
- Full Executive Strategic Card for all 36 cells.
- Pillar, Domain, Initiative, Outcome, KPI and Target mapping.
- Search by NSC, initiative, agency, KPI, pillar, domain or keyword.
- Traceability chain: Gap → Pillar → Domain → Initiative → Outcome → KPI → Target 2035.
- No sidebar.
